# Native Metal dispatch, expert I/O and command ownership

Fifteen complete host controller families are selected sequentially and pass the existing focused real GPU fixtures: index selection, Q8/F16 dense projection, scalar and batch attention, routed batch and single-token MoE, expert cache/table/load transactions, output projections, RoPE, compression, command/parallel/deferred scheduling, embedding/gather and general quant projection. Original MSL and arithmetic kernels are unchanged. This is the first combined integration checkpoint; final Debug/model/performance results follow in the final report.

Native owners construct actual shared packets and own admission, pipeline choice, geometry, scheduling and failure policy. Sole entry files publish existing C ABIs. Objective-C leaves retain ARC resources, cache PSOs and send Metal messages. The actual expert and command records move once; no Engine/Session mirrors are introduced. Cache and Loader share one actual native process configuration record after source review confirmed both objects could instantiate their original private once-config variables.

The C-after-record-move control passes the full kernel and DeepSeek Metal suites, scalar index additions, dense MPP and all three SSD expert formats. Each native selection is compiled then measured with focused fixtures before the next. Results include exact compressor/RoPE cases, half-KV gather byte guards, 15 expert-numeric rows across formats, output projections through large row counts, and ordinary/inexact-path numerical oracles. These are functional correctness checks, not timing claims. Full parallel FFN4096/TP-world2 admission and deferred fused-store scheduling need their direct fixture; ordinary5120 model execution alone does not cover them.

One real runtime error was found: @min inferred a bounded narrow integer for packed-gather threads, making its ceil-grid expression overflow and dispatch zero groups. Explicit u64 launch arithmetic fixes the unchanged existing half-cache byte guard. The failing whole/isolated runs and temporary trace are retained; the tracing code was removed. Other integration corrections are compiler-visible names, enum widths, shared visibility, actual POSIX declarations, crossed fallback guards and a cyclic shared header split. The authoritative base packet declarations now live once in bridge_types.h; bridge.h aggregates owner headers.

The newly added deferred-attention test initially assumed packed fusion was bit-identical to separate operators. Original C disproved that:28,392/32,768 values differ, maximum absolute8.46558e-9. The corrected new fixture keeps exact nonpacked comparison, finite checks, all ULP/bit diagnostics and the existing attention oracle bound3e-5*(1+|reference|) for packed fusion. No prior assertion, shader or runtime tolerance changed. Both original failed assumptions remain recorded.

The pressure guard remains unchanged; C control and each candidate run are serialized. The final activation driver lost its output pipe after quant's full Metal suite passed; its return120 is not a passing run. Only the missing output fixture was resumed separately, with its actual success recorded before marking Quant qualified. Useful binaries stay in .workspaces; compact commands, failures, source identities and compressed diagnostics are versioned here.
