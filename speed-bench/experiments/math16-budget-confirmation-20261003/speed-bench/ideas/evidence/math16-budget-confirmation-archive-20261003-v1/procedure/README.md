# Math16 released evidence archive procedure

This package performs no model, helper, guard or scoring execution. It packages the
original 48 first attempts on 16 fixed problems after explicit ROOT release. The
producer and independent audit remain the scoring authorities. An audit PASS is
not a conversion of the original producer rc3 to a successful model-job status.

`source-authorities.json` freezes the reviewed 104 plan assets, their actual modes,
43 V1 preparation/literal/refusal files, the independent audit source, and the
earlier immutable MAIN runtime100 authority. The known Python launcher and SDK
library leaf aliases retain exact link text and resolved target identity. Copied
payloads are regular files; large payloads retain original source pointers.

The first workspace-registration refusal is retained in
`administrative-first-refusal.json`. No production outcome was read during this
source preparation. All tests use clearly marked synthetic producer artifacts.

Before packaging, ROOT reviews the frozen source, registry, execution plan and CPU
proof and separately authorizes the post-release archive command. The tool first
validates the explicitly pinned release, actual guard and all pressure samples;
only then does it read the explicitly pinned producer summary and independent
audit. It requires their complete 48-attempt status, source/hash chain, typed
counts, rc0/rc3 semantics and both paired discordances to agree. No attempt files
are opened before those gates pass.

After those gates, it verifies MAIN runtime100 against the earlier pinned
authority, checks all 16 ordered rows and original full token/prompt/text hashes
in each of the three external sibling arm directories, and checks every original
static asset. It then uses an exclusive destination, copies all prepared/run/
pressure and arm files at most 2 MiB, and records SHA256, size, mode and original
path for larger files. It never retries into a partial destination. A post-copy
failure retains the partial files and a refusal JSON. A second runtime100 check
and the complete physical index finish packaging.

The index excludes only the exact top-level `manifest.json`; nested manifests,
logs, refusals and execute bits remain indexed. No current MAIN snapshot supplies
expected runtime hashes. Runtime checks include source/object/header/shader bytes;
they do not open the GGUF. Original models and defaults are untouched.

To publish after successful packaging: under the shared jj mutation lock, track
all explicit owned archive files with `--include-ignored`, run normal `jj status`
to materialize the snapshot, then verify all physical bytes and execute modes
against `jj --ignore-working-copy --color never file show` and `git ls-tree`.
Freeze a new evidence commit before ROOT performs a separate import. Verify the
runtime100 authority again before and after that import. Never substitute a
file-list view from before the snapshot has materialized.

Reported scope is one set and one seed: preserve original wrong/INVALID/capped
attempts and both discordances. Here raw files are token-piece **text bytes**, not
full-vocabulary logits. This archive supports no cross-prefix KL/NLL, equal-quality,
quantization-causality, speed, SSD, generalization or default-promotion claim.
