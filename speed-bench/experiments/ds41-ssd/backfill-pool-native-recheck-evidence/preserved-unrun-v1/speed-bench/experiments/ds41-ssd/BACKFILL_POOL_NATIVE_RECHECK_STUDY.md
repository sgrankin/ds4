The six serial arms are native-before, BF0, pool1600-off, pool1600-recheck, pool1600-recheck-repeat and native-after. All use the original calibration16×32 inputs/reference,ctx4096/cache64/chunk512 and exact earlier one-slot guards GAP.30, mass.20, total.35, rank48. Only POOL_NATIVE_RECHECK0 versus1 changes between the pool controls; READY age1600, queueTTL80, late1,400MiB ownership and all other gates are fixed. No held-out case or outcome is used for selection or tuning. Frozenf4 runtime is independently reviewed; no defaults are promoted.

The frozen literal065 fixture frontend is already linked against the separatef4 objects. Full512 unmodified candidate float rows and metadata are retained. Every arm enables final PROBE_IO. Exact logical demand reads plus all global and pooled background read/teardown bytes are summed once; cache_loader_bytes are not added again. Recheck not_started_bytes is a separate unstarted logical request observation, not a credit against actual requested/returned bytes and not a physical SSD traffic estimate. Queue conservation adds queue_native_resident_drops as a disjoint term. All prior completed/READY/expiry/age/queue/worker/allocation/fd/cap/late-install balances remain strict; foreign owner attempts or failed reads/installations reject the run. Quality summaries retain all16 prompt means, paired2000-resample bootstrap with seed20261002, tail KL and argmax flips. Timings are diagnostic only.

Preparation reads only the16-byte old raw header/size and copied input hashes; it never opens a model, initializes Metal, reads model metadata, hashes/copies the full raw reference or inspects text for policy selection. The full reference SHA and model stat are first verified under the exact prepared MAIN pressure-guard parent and held lock. Manifest SHA is explicit in prepared argv and exact parent suffix; the pinned framework interpreter and complete64-file input/helper/shader inventory are checked before model stat. All inherited names starting with literalDS4 are removed. No automatic retry or second job is launched. Separate ROOT model grant is required.

Seventy-five model-free CPU trials cover all old parser/lifetime/balance checks, large uint counter handling, the new queue-removal/byte classification, duplicate/missing/incompatible recheck footers, exact old raw+IO controls, fixed policy identity, manifest+command tampering with an old argv digest, parent aliases/suffix/interpreter/lock failures and omitted/foreign input/shader paths. Source, objects, helpers, command, manifest, input hashes and proof are frozen before any grant. Test source and captured JSON result digests have distinct explicit labels.
