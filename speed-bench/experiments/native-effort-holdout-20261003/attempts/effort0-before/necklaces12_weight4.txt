Alright, let's go step-by-step.

We have **12 beads total**, **4 black**, **8 white**.  
Rotations are considered the same, but reflections are considered different unless they are also rotations.

---

### Step 1 – Total arrangements ignoring rotations
If all beads were distinct, there would be \(12!\) arrangements, but here beads of the same color are indistinguishable.  
Number of distinct linear arrangements (in a fixed position) =  
\[
\binom{12}{4} = 495
\]
But this is for a straight line, not for a circle.

---

### Step 2 – Burnside’s Lemma for rotations only
We are dealing with **rotations only** first (necklaces, not bracelets).  
Group = cyclic group \(C_{12}\), order 12.

We need to count colorings with exactly 4 black, 8 white, fixed under each rotation.

**Rotation by k positions** (k from 0 to 11):  
The rotation splits the 12 positions into \(\gcd(12,k)\) cycles, each of length \(12 / \gcd(12,k)\).

For a coloring to be invariant under the rotation, each cycle must have all beads the same color. Thus, the number of black beads must be a multiple of the cycle length, and the number of cycles must accommodate 4 black beads.

Let \(d = \gcd(12,k)\), number of cycles = \(d\), cycle length = \(12/d\).

Number of black beads per cycle is either 0 or cycle length if cycle is black. But total black beads = 4.  
We need \(4\) to be divisible by cycle length \(12/d\). That means \(12/d\) divides 4.

Check possible \(d\):

- \(d=1\): cycle length 12, 12 doesn't divide 4 → no fixed coloring.
- \(d=2\): cycle length 6, 6 doesn't divide 4 → no.
- \(d=3\): cycle length 4, 4 divides 4 → possible: 1 black cycle, 2 white cycles. Number of ways = choose which cycle is black: \(\binom{3}{1} = 3\). But wait, check: cycle length 4, one black cycle means 4 black beads, yes. That matches. So 3 colorings.
- \(d=4\): cycle length 3, 3 doesn't divide 4 → no.
- \(d=6\): cycle length 2, 2 divides 4 → 2 black cycles, 4 white cycles. Number of ways = \(\binom{6}{2} = 15\).
- \(d=12\): cycle length 1, 1 divides 4 → choose 4 cycles to be black among 12: \(\binom{12}{4} = 495\).

Now, we must check which k have which d:

- \(d=1\): k with gcd(12,k)=1: k=1,5,7,11 → 4 rotations, each fixed colorings = 0.
- \(d=2\): gcd=2: k=2,10 → 2 rotations, fixed = 0.
- \(d=3\): gcd=3: k=3,9 → 2 rotations, fixed = 3 each.
- \(d=4\): gcd=4: k=4,8 → 2 rotations, fixed = 0.
- \(d=6\): gcd=6: k=6 → 1 rotation, fixed = 15.
- \(d=12\): k=0 (identity) → 1 rotation, fixed = 495.

Sum of fixed colorings over all 12 rotations:  
\(2\times 3 + 1\times 15 + 1\times 495 = 6+15+495 = 516\).

Burnside: number of distinct necklaces under rotations = \(516 / 12 = 43\).

So **rotations only**: 43 necklaces.

---

### Step 3 – Now include reflections as different unless also rotation
We have the dihedral group \(D_{12}\) of order 24 (rotations + reflections). But the problem says: "reflections are counted as different unless they are also rotations."  
This means: we do **not** quotient by reflections, except if a reflection gives the same as some rotation (i.e., the necklace is symmetric under that reflection). But in counting distinct objects, we are still using rotations as the only equivalence. So bracelets? No—bracelets identify reflections; here reflections are not identified unless they coincide with a rotation.

Actually, re-reading: "rotations are identified but reflections are counted as different unless they are also rotations" — means two necklaces that are mirror images are considered different unless the mirror image can be obtained by a rotation. So equivalence is still only by rotation group \(C_{12}\), not \(D_{12}\).  
That means the count is exactly the same as rotations-only count, i.e., **43**.

But wait—if reflection coincides with rotation, that means the necklace has a reflection symmetry that is also a rotation symmetry (only possible if reflection = rotation in the group action for that particular necklace). In \(C_{12}\) vs \(D_{12}\), a reflection is never a rotation in the group (except trivial?), so this "unless" clause doesn’t change anything for distinctness—it just clarifies that you shouldn’t collapse mirror images unless they are actually the same by rotation. That’s exactly the rotation-only equivalence. So answer remains 43.
