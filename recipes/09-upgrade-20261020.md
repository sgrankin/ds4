The matching BF16 vision encoder is
`gguf/DeepSeek-V4.1-Flash-1017-vision-BF16.gguf`. The downloader's older
`ds41f-vision` target still supplies the September encoder for the older model;

```sh
./download_model.sh ds41f-q2
./download_model.sh ds41f-1017-vision
./ds4-local persistent-fast \
  --model gguf/DeepSeek-V4.1-Flash-1017-IQ2_XXS-Q2_K-imatrix.gguf
```

## First 1017 qualification and repeated relocation

All **16 first-attempt checks passed** on the verified 1017 language/vision pair:
six native-server checks cover ordinary generation, Responses create/get,
`previous_response_id`, Conversations recall and actual image OCR. Ten
`persistent-fast` agent checks cover five completed turns, opaque-ID deletion
and retained-ID stability, verbatim archival, a fresh storage answer with a
visible retrieval tool, one accepted edit without automatic compaction, and a
fresh coding implementation passing eight cases plus input preservation.
The agent used temperature 0, no thinking, context 16,384, prefill chunk 2,048,
hot state cache 0 MiB and SSD cache 4,096 MiB. These settings differ from the preset's default chunk.
Server and agent exited cleanly; this is a tiny compatibility/quality screen,
not a paired speed benchmark. No suffix graft activated in this agent screen.
[First results](../speed-bench/experiments/1017-upgrade-20261020/qualification/result.json),
[coding grade](../speed-bench/experiments/1017-upgrade-20261020/qualification/agent/coding-grade.json).

The separate existing relocation probe captured one immutable source and reused
513 tokens with 128 fresh tokens for each move: right 66, left 128, right 514.
The summed edit work fell **205.185 → 143.068 seconds (30.27%)**. This excludes
source setup and teacher continuation; it is edit-time saving, not whole-agent
saving. Both state/original hashes remained unchanged across all three moves.
Across only 12 easy fixed-teacher rows, mean ΔNLL was +0.00006524 nats/token and
mean KL was 0.00003049; maximum ΔNLL was +0.0002171 and KL was 0.0001108. There were zero argmax
flips, while all 12 logit rows differed bytewise. This demonstrates repeated
relocation without progressive mutation of the source, not broad task quality.
[Move/quality summary](../speed-bench/experiments/1017-upgrade-20261020/repeat/summary.json).

These findings do not transfer the historical 23.52% coding saving to 1017.
Mixed-prefill-quantum latency is a separate experiment; its status and results
belong in the [official-source chapter](08-official-inference-lessons.md).
